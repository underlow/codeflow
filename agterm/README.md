# Наши настройки и скрипты agterm

Снимок рабочего комплекта от 4 ноября 2026 года. Здесь находятся исходники,
переносимые фрагменты конфигурации и установщик для восстановления на другом Mac.
Это отдельный комплект: основной установщик CodeFlow его автоматически не запускает.

## Что сохранено

| Функция | Исходники | Куда устанавливается |
|---|---|---|
| Автоматическая строка активности Codex / Claude Code | `activity/` | `~/.local/bin/agterm-activity.py` |
| Annotate: выделение или последние 50 строк терминала → revdiff → заметки | `files/.local/bin/annotate-pane.py` | тот же путь относительно `$HOME` |
| Annotate replies: ответы Claude после последнего запроса → revdiff → заметки | `files/.local/bin/agterm-annotate/` | тот же путь относительно `$HOME` |
| Claude Recap: краткая сводка разговора | `files/.config/agterm/scripts/claude-recap.zsh` | тот же путь относительно `$HOME` |
| Yazi в overlay и вставка выбранного пути | `files/.config/agterm/scripts/yazi-*.zsh`, `files/.config/yazi/plugins/` | те же пути относительно `$HOME` |
| Горячие клавиши и команды agterm | `files/.config/agterm/keymap.conf` | `~/.config/agterm/keymap.conf` |
| Esc закрывает основной просмотр revdiff | `files/.config/agterm/annotate-pane.keys` | тот же путь относительно `$HOME` |
| Статусы агентов и shell-интеграция | `files/.config/agterm/agent-status/` | тот же путь относительно `$HOME` |
| Заголовки Ghostty / Codex только внутри agterm | `config/zsh-title.zsh` | блок в конце `~/.zshrc`, после Oh My Zsh |
| Подключение shell-интеграции | `config/zsh-status.zsh` | отмеченный блок в `~/.zshrc` |
| Claude status line и привязка transcript к панели для Recap | `files/.claude/statusline-command.sh` | тот же путь + `statusLine` в Claude settings |
| Хуки Claude для статусов и Annotate replies | `config/claude-hooks.json` | слияние с `~/.claude/settings.json` |
| Хуки Codex, `hooks = true`, `daemon_auto_start = false` | `restore.py`, `activity/install.py` | слияние с `~/.codex/config.toml` |
| Shift+Enter в Yazi: вставить путь в исходную панель и закрыть Yazi | `config/yazi-keymap.toml`, Lua-плагин | `~/.config/yazi/keymap.toml` и `plugins/` |
| agterm-scoped Ghostty config и restore denylist | `files/.config/agterm/` | те же пути относительно `$HOME` |
| Внешний вид и режим восстановления приложения | `config/agterm-settings.json` | только с `--ui-settings` |

`files/` повторяет расположение файлов относительно домашнего каталога. `@HOME@`
в шаблонах заменяется установщиком на целевой домашний каталог. Не редактируй
установленные копии вместо этих исходников: после изменений установи их заново.

`agent-status/` — сохранённая копия штатных адаптеров agterm, не наша реализация.
Она нужна для воспроизводимости текущей настройки. Обновление через
**Help → Install Agent Status Hooks** может заменить её установленную копию.
Навык agterm также ставится штатно через **Help → Install Agent Skill**;
его исходники и бинарники терминала в этот комплект не входят.

## Восстановление

Нужны macOS, agterm с `agtermctl`, Python 3.11+ для установщика, zsh, jq, revdiff,
Yazi и установленные Codex / Claude Code. Python 3.9 из `/usr/bin/python3`
достаточен для самого обработчика активности. Снимок сделан на Apple Silicon:
у Yazi helper есть путь `/opt/homebrew/bin/agtermctl`; на Intel его надо адаптировать.
Авторизация агентов выполняется отдельно обычным способом.

Из этой папки:

```sh
python3.14 restore.py
```

Установщик копирует скрипты, подключает хуки обоих агентов, восстанавливает
status line Claude и zsh-интеграцию. Чужие хуки, политики Claude, trusted hashes
Codex и другие команды keymap сохраняются. Перед заменами создаются резервные
копии в `~/.config/agterm/codeflow-backups/<timestamp>/` и
`~/.config/agterm/activity-backups/<timestamp>/`. Скрипты из `files/` по тем же
путям заменяются снимком; исходные файлы остаются в резервной копии.

После установки:

1. В agterm перезагрузи keymap и config через меню File.
2. Открой новые shell-сессии для изменений `.zshrc`.
3. В Codex открой `/hooks` и доверь новые хуки `agterm-activity` и штатные agterm,
   если это новая машина. Trusted hashes намеренно не переносятся между машинами.
   При необходимости перезапусти / resume CLI для загрузки конфигурации.
4. В Claude проверь `/hooks`; при необходимости открой новую сессию.
5. Если уже запущен общий Codex daemon, одних новых настроек недостаточно:
   он мог унаследовать окружение другой панели. Дождись окончания его сессий,
   затем отдельно останови daemon и запусти CLI заново. Установщик его не останавливает.

Для восстановления внешнего вида сначала закрой agterm и выполни:

```sh
python3.14 restore.py --ui-settings
```

Этот флаг восстанавливает только сохранённые предпочтения приложения, включая
`restoreMode: none`; окна, процессы и история терминала не переносятся.

Репетиция без изменения рабочего домашнего каталога:

```sh
python3.14 restore.py --home /tmp/agterm-restore-demo
python3.14 -m unittest discover -s activity -v
python3.14 -m unittest test_restore -v
```

## Команды и поведение

| Команда | Сочетание |
|---|---|
| Annotate | Ctrl+Option+Shift+Cmd+X |
| Annotate replies | Ctrl+Option+Shift+Cmd+E |
| Yazi | Ctrl+Option+Shift+Cmd+A, затем Y |
| Claude Recap | через command palette, отдельной клавиши нет |

Annotate использует выделение, а без него — последние 50 строк панели. Заметки
попадают в основной prompt через clipboard / bracketed paste без отправки;
для split-right и scratch остаются в clipboard для ручной вставки.

Annotate replies работает с Claude, использует указатель transcript от Stop hook,
читает его заново и по умолчанию отправляет замечания автоматически. Не следует
нажимать команду во время ручного редактирования prompt: доставка использует
ввод / paste и Return. Клавиши Esc задаются отдельным файлом revdiff.

Recap получает точный transcript панели через Claude status line, а при отсутствии
привязки ищет последний transcript для каталога. Второй вариант неоднозначен,
если несколько разговоров работают в одном каталоге. В отличие от activity,
Recap делает отдельный запрос Claude: модель задаётся `RECAP_MODEL`, текущий
снимок использует `claude-haiku-4-5-20251001`, `--safe-mode`, без инструментов.

Yazi открывается в overlay 95%. Shift+Enter экранирует выбранный путь, вставляет
его в исходную панель по стабильному pane ID и закрывает Yazi. Команда не отправляется.

Заголовки zsh действуют только при `AGTERM_ENABLED=1`: у свободного shell —
`Ghostty`, у запущенного Codex — `Codex`. Остальные заголовки остаются динамическими.

## Строка активности

`UserPromptSubmit` показывает **Работаю**: сообщение отправлено, ход начался,
но инструмент ещё не вызван. После инструмента показывается **Думаю**.
Остальные тексты: **Читаю · файл**, **Читаю много файлов**,
**Редактирую · файл**, **Редактирую файлы**, **Ищу в коде**, **Ищу файлы**,
**Тесты · задача**, **Build · задача**, **Lint · задача**, **git diff**,
**git status**, **git log**, **git show**, **Git · операция**,
**Выполняю · программа/скрипт**, **Выполняю команду**, **Выполняю**,
**curl**, **ssh**, **agterm**, **Гуглю**, **Читаю веб**, **Смотрю картинку**,
**Зову коллегу**, **Жду ответа**, **Жду подтверждения**, **Жду команду**,
**Упс, компакт**, **Ошибка**, **Готово**, **Что не так?**,
**Инструмент · название**. На старте сессии — **Готов к работе**.

Ограничения и устройство обработчика описаны в [activity/README.md](activity/README.md).
Он не обращается к модели. Несколько вызовов объединяются через `/`, параллельные
инструменты отмечаются `(+N)`. Без обновлений строка исчезает через 10 минут.
**Готово** означает завершение ответа, а не доказанное выполнение всей задачи.
Событие ошибки и реальное ожидание разрешения сейчас доступны через хуки Claude;
сам `PermissionRequest` Codex не считается ожиданием человека из-за Auto Review.

`activity/watch_session.py` — временный наблюдатель для живой проверки уже открытого
Codex до загрузки новых хуков. Он читает только новые записи transcript; формат
внутренний и может измениться. Его не надо запускать одновременно со штатными
activity hooks той же сессии. После проверки останови его процесс.

## Что не включено

Не сохраняются полные конфиги агентов, авторизация, разговоры, содержимое
clipboard, временные transcript pointers, кэш заметок, резервные копии рабочего
Mac, состояния окон и сессий agterm. `hooks.conf` сейчас содержит только штатные
закомментированные примеры: активных пользовательских event hooks в нём нет.
Standalone Ghostty не менялся и не переносится.

## Проверено

Оставлены проверки отдельных сценариев разбора и изоляции событий, вызова
обработчика отдельным процессом и сохранения посторонних настроек / резервных
копий при установке и восстановлении. Они не доказывают корректность работы
нескольких процессов или доставки штатных hooks обоих агентов. Наблюдатель
проверялся отдельно на реальных вызовах в Codex-сессии. Для shell-скриптов проверялся
синтаксис. Ручное повторное прохождение Annotate, Recap, Yazi и live Claude
в рамках упаковки не выполнялось; Recap не запускался и модель не вызывалась.
