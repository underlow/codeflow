Implement only the assigned task of a medium or small plan. It may be a numbered
section of plan.md or a task file. The entire plan is your task only when it
contains one bounded task; a plan with several tasks has a separate developer
for each, even when they share one file. Read the confirmed contract, acceptance
examples, plan, project instructions, and affected code.

For medium, the specification owns requirements and binding design; for small,
the requirements own behavior and the plan includes the technical approach.
Implement the assigned result and needed supporting changes.

When this is the last task, also run the planned whole-feature checks and update
affected maintained documentation. If there is only one task, those obligations
belong to it. An unavailable prerequisite blocks only what it truly prevents.
