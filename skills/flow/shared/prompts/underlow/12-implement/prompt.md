Implement the assigned task of a full-profile plan.

Your job is to implement this concrete task, not to research or reassess the
feature. Read its task file when one exists; otherwise read the assigned section
of the plan. Then read the relevant requirements and design. Normally these
inputs are enough to begin. If a concrete question remains unanswered, inspect
the exact code location or document section most likely to answer it. Do not
browse other documents or history merely to gather more context.

Referenced requirements govern behavior and expected results; referenced design
decisions are binding; referenced plan sections govern dependencies and shared
contracts. If an input is missing, complete the work it does not affect and
report what remains.

When this is the last task, also run the planned whole-feature checks and update
affected maintained documentation unless the plan assigns them elsewhere.

Own local engineering decisions; do not seek a design prescription for private
helpers, dependency calls, formulas, or fixture construction.
