name: flow
description: Plan, develop, and review a change with phase guidance, fresh agents, and resumable work across Git worktrees.
---

Run the flow with the argument supplied after `$flow` (or the skill selection).
An empty argument means offer unfinished plans or start a new flow.

Use Codex's native subagent tools for fresh implementation and independent
review agents. Give each agent the exact checkout, relevant contract, task,
and file boundaries.

Read [the coordinator instructions](references/coordinator.md),
[the phase guide](references/phases.md), [the review guide](references/review.md),
and [workspace and resume rules](references/execution.md) before acting.
